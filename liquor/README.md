# 갓잇 음,주류 통합사이트 앱 설치용 페이지

이 페이지를 PC · 휴대폰 · 태블릿 Chrome에서 열고 "앱 설치"를 누르면 홈 화면(바탕화면)에 갓잇 음,주류 통합사이트 앱이 생깁니다.
실제 화면과 데이터는 구글 Apps Script 서버에서 그대로 불러오며, 이 저장소에는 데이터가 없습니다.

- 주소: https://hmkim-dev.github.io/liquor/
- 아이콘을 바꾸려면 icon-v*-*.png 파일 이름의 버전(v1→v2)을 올리고 index.html·manifest.webmanifest·sw.js의 파일명과 sw.js의 CACHE 이름을 같이 바꿔야 휴대폰 아이콘이 갱신됩니다.
